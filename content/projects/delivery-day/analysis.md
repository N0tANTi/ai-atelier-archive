## 一、 三套实时美术画风（`1 / 2 / 3` 零刷新热切换）

通过 `src/styles.js`、`src/toon.js` 与 `src/post.js` 联动，同一套 3D 几何可在飞行过程中瞬间切换三种截然不同的绘本气质：

| 按键 | 画风 | 色彩与大气特征 | 后处理与细节亮点 |
| :--- | :--- | :--- | :--- |
| **`1`** | **莫比乌斯 · 清线**（默认） | 薄荷青过渡至蜜桃粉天空，空中悬有巨型光环行星、新月与细轨道弧 | 极细梅紫墨线描边（按距离衰减）、阴影交叉排线、水彩宣纸肌理、飘浮马卡龙色热气球 |
| **`2`** | **吉卜力 · 晴夏** | 明亮蔚蓝晴空与高太阳侧逆光，冷蓝阴影配暖陶红屋顶 | 丝绒感羽化积云、暖水粉笔触质感、蓬松云团状植物树冠 |
| **`3`** | **金色 · 黄昏** | 暮紫至杏橘晚霞天幕，暖橘低角度斜射光 | 液态金闪烁海面、旋转扫描的灯塔体积光束、全城亮起的暖色窗灯与街灯 |

## 二、 两座纯代码程序化城市（零外部 3D 模型）

通过顶部工具栏或 URL 参数 `?city=harbour` / `?city=prague` 可在两座完整城市间切换，底层共用同一套飞行、材质与后处理管线：

### 1. 地中海海港风车城（`src/world.js`，默认）
- 依山坡拾级而上的 3~4 层地中海住宅群（陶红斜屋顶、奶油/赭黄/淡粉/薄荷灰泥墙、红天竺葵窗台与晾衣绳）。
- 核心飞行地标：绿铜尖顶钟楼广场、穹顶教堂、4 座山顶旋转风车、6 孔石拱高架桥、**可驾扫帚穿行的海上石灰岩拱门**、红白灯塔及冒烟小蒸汽船。

### 2. 布拉格百塔河谷（`src/prague.js`）
- 蜿蜒的伏尔塔瓦河、5 孔查理大桥（带切水桥墩、两侧雕塑与两岸桥头塔）、老城广场（含**金针跟随真实时刻走动的天文钟**与泰恩教堂黑色双尖塔）、小城区、布拉格城堡、圣维特大教堂（飞扶壁、玫瑰窗与绿铜穹顶）以及佩特任瞭望塔。
- **千屋合批性能巧思**：布拉格上千栋建筑将窗户改为平面手绘面片，并自动剔除院落内侧与邻墙贴合面，合并为极少量 Mesh，在轻量化显卡上也能稳定流畅飞行。

## 三、 角色雕塑、浮空操控与纯代码音频

- **小魔女与黑猫（`src/rider.js`）**：纯程序几何雕琢的短发层次、随空速翻飞的双环大红丝带、实时布料波动的百褶裙、雕木笔刷尾扫帚、晃动黄铜小提灯、皮书包卷轴，以及俯冲时压低双耳、慢飞时左顾右盼的小黑猫。
- **无压飞行与软碰撞（`src/main.js`）**：自动温和巡航，遇建筑/海面柔和推离无坠毁，穿入云团出现短暂云雾白化；第三人称相机带平滑滞后、动态 FOV 与轻微压坡横滚。
- **纯 Web Audio 合成声景（`src/audio.js`）**：零音频文件下载，全程运行时合成风噪呼啸、海鸥鸣叫、海浪、远处汽笛，并在布拉格模式下切换为高低音应答的教堂钟声与远方电车铃声。

## 四、 快捷键与录屏 URL 参数速查

| 按键 | 功能 |
| :--- | :--- |
| `W / S` 或 `↑ / ↓` | 加速 / 减速（可减至近乎悬停） |
| `A / D` 或 `← / →` | 左右压坡转弯 |
| `Space / Shift` 或按住鼠标 | 爬升 / 下降 |
| `1 / 2 / 3` | 实时切换：莫比乌斯清线 / 吉卜力晴夏 / 金色黄昏 |
| `C` | 切换三机位：飞行跟随 / 广角全景 / 魔女特写 |
| `P` | 开关自动风景巡航（解放双手观赏/录屏） |
| `H` / `M` | 隐藏全部 UI（纯净录屏） / 静音合成音景 |

### 实用直达参数
- `?style=moebius` / `?style=ghibli` / `?style=golden`：指定开场画风
- `?city=harbour` / `?city=prague`：指定开场城市（海港风车城 / 布拉格河谷）
- `?auto&clean`：自动巡航 + 隐藏所有 UI（电影感展示模式）
- `?fps`：显示实时帧率；`?at=x,y,z,yaw`：指定出生坐标与朝向
