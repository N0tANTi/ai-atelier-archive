## 一、 为什么它不用光追、不打远景灯，却极具电影感？

在浏览器里渲染一座包含数百栋摩天楼、大河倒影、400 多个发光酒瓶与多房间光影的 1929 年深夜爵士酒吧，如果按传统思路狂堆实时点光源与反射，显卡瞬间就会掉帧。

《月光下的夜城（The Blue Hour）》基于 **Three.js `WebGPURenderer` + TSL**，用极高明的三处「视觉减法」骗出了版画与老电影般的质感：

## 二、 三大核心视觉巧思

### 1. 远景「玻璃绘景」叠层 + `2048×1` 一维河面倒影（`src/world/city.ts`）
- **零实时灯光的天际线**：对岸几百栋装饰派（Art Deco）尖顶高楼全部关闭真实光照计算，直接走自发光通道。代码模仿好莱坞老电影「玻璃绘景（Matte Painting）」分层上色——近岸深藏青剪影、中景深蓝阶梯塔楼、远景灰蓝退晕，并在楼群间插入 3 层半透明薄雾面片拉开空气透视；所有暖色亮窗基于 `fwidth()` 屏幕导数做抗闪烁程序生成。
- **1 像素高的伪光追倒影**：没有跑昂贵的平面反射 Pass，而是在场景初始化时，把对岸所有路灯与亮窗的水平发光分布压缩烘焙进一张 **`2048 × 1` 的一维纹理**；河面着色器只需按横向波纹噪点扰动采样并纵向衰减，就能拉出以假乱真的摇晃琥珀光柱。

### 2. 受光与自发光彻底分家：硬漫画 × 柔霓虹（`src/render/pipeline.ts`）
- **MRT 统一量化色带**：渲染管线通过多渲染目标（MRT）同时输出画面（Lit）、固有色（Albedo）、自发光（Emissive）与深度（Depth）。后处理先扣掉自发光再除以固有色，反推出纯光照强度并量化成 3~4 层硬朗色带，再用深度二阶差分在近景折角处描 1px 细墨线。
- **该硬的像版画，该柔的留光晕**：桌椅、墙面、人物呈现利落的美式漫画硬边；而台灯罩、吧台 400 多个酒瓶、上升的烟丝与窗外整座夜城全部走自发光通道，绕开色带切割保留温润霓虹辉光。

### 3. 像素级空间分区调色：一扇门隔开冷暖两重天（`src/world/looks.ts` + `src/render/pipeline.ts`）
- 普通全屏调色滤镜一旦偏暖，门外月夜就会一起发黄串色。
- 这里在最终调色阶段通过**深度反推每个像素的三维世界坐标**，实时判定它落在哪个房间包围盒内：
  - **主厅（Amber Hall）**：浓郁暖琥珀金，衬托舞台爵士乐队与彩绘玻璃；
  - **西侧牌室（Card Room）**：压低为冷艳蓝紫调台灯氛围；
  - **露台与夜城（Night Balcony）**：推门即见清冷深邃的月光蓝。

## 三、 内置公版老唱片与开源资产说明

- **音乐与声景（`src/audio/club-audio.ts`）**：舞台乐队循环演奏 4 首 1923–1924 年真实公版爵士录音（*In the Evening*、*Bleeding Hearted Blues*、*Spain*、*Wild Cat Blues*），搭配木地板脚步声与打火机音效。
- **许可洁净性**：仓库代码采用 MIT，自建模型与程序场景采用 CC0 1.0，5 件道具为 CC BY 4.0（详见仓库 `ASSETS.md` 与 `MISSING_ASSETS.md`）。受第三方分发许可限制的 Mixamo 动作剪辑与 Sonniss 环境音未包含在公开仓库中，角色以静态姿态呈现，按 `MISSING_ASSETS.md` 指引可自行补回完整音画。

### 操控与本地运行

```bash
git clone https://github.com/N0tANTi/the-blue-hour.git
cd the-blue-hour
npm ci
npm run dev
```

| 按键 | 操作 |
| :--- | :--- |
| 点击画面 + 鼠标移动 | 环视 1929 爵士酒吧与高空露台 |
| `W / A / S / D` | 第一人称漫步 |
| `Shift` | 加快脚步 |
| `Esc` | 暂停与释放鼠标 |
