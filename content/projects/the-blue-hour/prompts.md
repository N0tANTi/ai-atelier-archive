## 一、 4 张核心「大夜景减法渲染」Prompt 卡片

### 卡片 #1｜近景立骨 · MRT 多目标与硬漫画色带（Stage 1）
```text
[PROMPT 01 · 后处理统一反推光照 + 1px 折角墨线]
1. 不要给每个物体单独写复杂卡通材质，使用多渲染目标（MRT）同时输出画面、固有色（Albedo）、自发光（Emissive）与深度
2. 在后处理通道用 (lit - emissive) / albedo 反推纯光照强度，量化成 3~4 层硬朗漫画色带
3. 利用深度二阶差分在近景建筑与器物折角处描 1px 细墨线，做到近处像美式版画般利落
```

### 卡片 #2｜远景绘画 · 免打光「玻璃绘景」叠层（Stage 2）
```text
[PROMPT 02 · 自发光天际线 + 薄雾纵深 + 抗闪烁窗灯]
1. 远处数百栋装饰派摩天大楼完全关闭实时受光，全部写入自发光通道（直接绕开后处理漫画色带切割）
2. 按距离将楼群涂成「近岸深藏青剪影 → 中景深蓝阶梯塔楼 → 远景灰蓝退晕」，楼宇间插 3 层半透明薄雾面片拉开空气透视
3. 摩天楼窗户采用基于屏幕导数 fwidth() 抗闪烁的程序化暖光簇点亮，零贴图且远观绝不闪烁
```

### 卡片 #3｜水面借光 · 2048×1 一维光带伪造倒影（Stage 3）
```text
[PROMPT 03 · 零光追开销的碎金河面倒影]
1. 不跑平面反射 Pass 也不做实时光线追踪，把算力留在刀刃上
2. 初始化阶段将对岸所有路灯与亮窗的水平位置投影，压缩烘焙成一张 2048×1 的一维发光分布贴图
3. 在水面着色器里采样该一维光带，叠加横向波纹噪点并做纵向衰减，实时拉出摇晃的琥珀碎金光柱
```

### 卡片 #4｜同框守色 · 像素级房间包围盒调色（Stage 4）
```text
[PROMPT 04 · 一扇门隔开冷暖两重天]
1. 放弃全屏一刀切的统一滤镜，避免推门望向室外时室内外严重串色
2. 在最终调色阶段通过深度缓冲反推每个像素的三维世界坐标，判断其落入哪个空间包围盒
3. 按空间独立套用色板：大厅守住浓郁暖琥珀金、西侧牌室压成冷艳蓝紫、露台外夜城保持清冷深蓝月色
```

## 二、 完整工程级 Prompt 模板（大夜景减法架构蓝图）

```markdown
请使用 Three.js（WebGPURenderer + TSL，自动兼容 WebGL2 回退）与 TypeScript，构建一个 1929 年装饰派（Art Deco）高空爵士酒吧与月光摩天夜城的第一人称探索场景。

### 全局美术铁律（Graphic Noir 减法原则）
- 零外部写实照片贴图，追求平涂美式黑色漫画（Graphic Noir）与老电影手绘背景质感。
- 严格区分「受光材质（硬色带 + 细墨线）」与「自发光元素（柔和光晕 + 绘景渐变）」，绝不用单一模糊滤镜糊掉全屏。
- 三个相连空间必须拥有独立色温且同框不串色：主厅暖琥珀金、西侧牌室蓝紫冷光、玻璃门外深蓝月夜。

### 模块化分阶段实现要求
1. **近景立骨 · MRT 后处理管线（Stage 1）**：
   - 使用多渲染目标（MRT）输出 Lit、Albedo、Emissive 与 Depth。
   - 在后处理中通过 `(lit - emissive) / albedo` 反推纯光照并量化为 3～4 阶硬色带，结合深度二阶差分在近景结构折角描 1px 细墨线。
   - 自发光通道（台灯、400+ 吧台酒瓶、上升烟丝与窗外夜城）绕过色带切割，保留通透光晕。
2. **远景绘画 · 免打光玻璃绘景夜城（Stage 2）**：
   - 对岸几百栋装饰派阶梯尖顶高楼完全不打实时灯光，直接以自发光分层着色（近岸藏青剪影 → 中景深蓝塔楼 → 远景灰蓝退晕）。
   - 楼群之间插入 3 层半透明薄雾面片构建空气透视，窗户用基于 `fwidth()` 抗闪烁的程序化暖光簇生成。
3. **水面借光 · 2048×1 一维光带倒影（Stage 3）**：
   - 初始化时将对岸路灯和亮窗的水平发光分布投影为一维 `2048×1` 纹理。
   - 河面着色器以横向水波噪点偏移采样该一维光带，并随距离纵向衰减，以极低开销呈现晃动的琥珀碎金光柱。
4. **同框守色 · 像素级空间分区调色（Stage 4）**：
   - 在最终合成阶段用深度反推每个像素的 3D 世界坐标，依据各房间包围盒平滑混合独立色板（琥珀大厅 / 蓝紫牌室 / 月夜露台）。
   - 接入 Rapier 第一人称平滑漫步与空间音效（1920s 爵士舞台音源 + 脚步声），推开玻璃门即可在室内外无缝漫游。
```
