## 一、 从海岛小镇到 22 层立体赛博巨城

为了突破传统平铺城建的纵深上限，项目对建筑生成、底盘空间与生态实体进行了全链路科幻重塑：

- **5 种未来摩天楼原型 + 3 种外立面光影**：
  1. 银翼杀手阶梯金字塔巨构；
  2. 双鳍赛博之门（中空悬浮发光菱形核心）；
  3. 曲面穹顶生态玻璃塔；
  4. 新东京巨幅霓虹广告刀锋塔；
  5. 悬挑顶层 + 轨道全息悬浮环与冲天激光束。
- **高密度立体结构**：将天际线拉升至 `15–22` 层，串联四层空中连廊与高对比银灰钛合金甲板，形成极具压迫感的摩天峡谷。

## 三、 24 小时昼夜霓虹管线与暗色玻璃 HUD

- **昼夜大气与真彩霓虹泛光**：自定义 GLSL 复合着色器平滑衔接 **金属银蓝白昼 → 金红黄昏（全城千窗霓虹同步点亮）→ 星空新月午夜 → 粉紫破晓**，通过双环真彩霓虹泛光（Multicolor Neon Bloom）保持青、品红、琥珀色光晕的高饱和分离度；
- **黑曜石毛玻璃 UI 与钢琴配乐**：重做 `src/ui/ui.css` 为暗色半透明玻璃工具栏，并在 `src/app/music.ts` 中嵌入定制钢琴主题 BGM（`public/music/cyberpunk-theme.mp3`），支持 `?lang=zh` 中文界面与 GitHub Pages 在线直玩。
