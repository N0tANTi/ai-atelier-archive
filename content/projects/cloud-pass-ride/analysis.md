## 一、 共享样条驱动的 320 米无限循环山道

`cloud-pass-ride` 没有把道路做成静态拼接块，而是以 **320 米循环样条** 作为整个世界的几何基准（`causeway.js`、`vista.js`、`meadow.js`）：

- **第 78–179 米连续 S 弯石堤**：桥面铺装、轮胎接地路径、石栏柱与桥拱均从同一条中心曲线采样，保证高速压弯时轮胎与路面、阴影严丝合缝；
- **速度与运镜编排**：开局约 `65 km/h`，首次下桥后直道加速至最高 `112 km/h`。入弯时依据曲率与车速动态计算车身倾角，跟车镜头先贴近后轮强化贴地感，随后自然抬升露出左侧水库与远山。

## 二、 深度还原近景拖影与 56 秒全天候系统

| 核心模块 | 实现机制 | 视觉效果 |
| --- | --- | --- |
| `ride.js`（近景拖影） | 片元着色器从深度缓冲还原世界位置，结合上一帧相机与路面位移计算运动向量 | 远山、石柱与路旁草叶呈现分层掠过速度，同时单独遮罩保护骑手主体不被糊掉 |
| `atmosphere.js` | 三组 Poly Haven 天空球、实时三维体积云、谷雾与草籽共享统一天气时钟（56 秒/轮） | 晴昼 → 夕照 → 风雨（湿润车辙反光）→ 月夜（车灯与远处城窗点亮）无缝过渡 |
| `slipstreams.js` | 随里程与侧风漂移的路肩流雾及边缘掠镜风线 | 迎着夕阳自动染上暖金色，系统开启 `prefers-reduced-motion` 时自动收敛 |

## 三、 骑手烘焙姿态与实时二级动画（`rider.js` / `hair.js` / `mantle.js`）

为了让人物在高速骑行中既有写实贴合度又不失动感，项目把资产分为「构建期烘焙」和「运行期物理」两层：

1. **构建期烘焙骑姿（`pack_head.py` / `pack_outfit.mjs` / `pack_models.mjs`）**：基于固定版本的 MakeHuman 服装、头模与 Tevy 跑车资产，沿统一骑姿骨架把夹克、牛仔裤、靴子与十指精准贴合车座、脚踏和握把，并在肘膝弯曲处细分网格压出自然褶皱；
2. **运行期动态细节**：
   - **头部与视线**：领口内置头部转轴，入弯主动转头并修正地平线倾角，骑行途中定时眨眼；
   - **分层马尾（`hair.js`）**：发根随头部刚性绑定，左/中/右三束发尾骨骼随车速抬升、过弯向外甩动，雨天则受重力下垂；
   - **短披肩布料（`mantle.js`）**：领口固定于肩线，轻量网格依据侧风与压弯实时翻卷，交替露出较暗内衬。

## 四、 可复现单文件构建与预览配乐链

仓库通过 `materials.json` 与 `riding_models.json` 锁定所有外部 CC0/开源素材的 URL 与 SHA-256 校验值，执行 `npm run build` 即可由 `build.mjs` 将全部模型、贴图与脚本打包为单个可离线运行的 `dist/index.html`；同时配套 `capture.mjs`（720p/30fps 实录）与 `score.mjs`（响度匹配音频切片）实现一键出片。
