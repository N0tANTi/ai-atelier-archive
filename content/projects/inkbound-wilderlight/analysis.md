## 一、 三幕东方影调演进系统

不同于简单叠加一层滤镜，`inkbound-wilderlight` 直接重写了世界材质、GPU 笔触调色板与大气光照控制器（`src/original-world.js`、`src/night-lighting.js`、`src/night-atmosphere.js`）：

1. **素雪墨林**：高明度宣纸霜雪地面 + 低饱和焦墨树干，点缀少量朱砂枫叶形成东方留白构图；
2. **残枫血月**：天穹压暗为墨靛夜空，血月低悬林梢，地面雪色转为冷青灰并拉高红枫与刀光对比；
3. **黑泽留朱**：致敬经典剑戟片的高反差黑白影调，仅保留朱砂红与墨焰高光，突出厮杀瞬间的戏剧张力。

## 二、 电影级全屏后处理管线

在 WebGL 2 渲染通道末端引入多层电影光学模拟：

- **深度缓冲真浅景深（Bokeh DOF）**：依据焦点距离虚化前景枝叶与远景墨林，强化镜头纵深；
- **宽银幕胶片光晕（Anamorphic Bloom / Halation）**：让朱砂火光与血月边缘散发出轻微水平拉丝与胶片暖晕；
- **丁达尔体积光束 + 宣纸肌理 + 35mm 动态颗粒**：将实时 3D 渲染画面统一到同一层物理纸墨与胶片质感下；
- **2.39:1 宽银幕画幅与去字化 UI**：进入观影模式自动隐藏全部数值界面，仅保留片名印章。

## 三、 飞白毛笔特效与五幕导演系统

| 模块文件 | 核心改造 | 交互/视觉收益 |
| --- | --- | --- |
| `src/advanced-effects.js` & `src/effects.js` | 用 UV 参数化 3D 飘带 + 自定义 GLSL 飞白笔触着色器替换原作纯色圆环 | 旋风斩、剑气、火阵与 Boss 预警呈现出墨迹枯笔飞白与朱砂拖尾 |
| `src/cinema-director.js` | 内置五幕导演脚本，自动接管机位轨迹、目标跟随与战斗升格慢动作 | 点击「观 影」即可体验完整无 UI 电影化短片流程 |
| `src/chapter-music.js` & `browser-audio.js` | 章节配乐与战斗音效联动切换 | 古琴、尺八与太古战鼓随昼夜和 Boss 阶段自然推进 |

## 四、 零构建直接托管与开源合规

项目保持原生 ES Modules 结构，无需 Webpack/Vite 构建步骤：本地运行 `py -3 start.py` 即可在 `http://127.0.0.1:8000/` 启动，仓库根目录通过 `.nojekyll` 直接托管于 GitHub Pages；同时完整清理了原作保留版权的宣传媒资，并附带 `LICENSE` 与 `THIRD_PARTY.md` 清楚注明全部第三方模型、音效与字体许可。
