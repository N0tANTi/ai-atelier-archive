## 一、 为什么它不是普通水彩滤镜？

市面上多数「水彩风格」只是给渲染好的画面套一层屏幕后处理模糊，而《水彩漫开》把画纸与颜料逻辑直接写进了几何与着色管线底层：

1. **先画铅笔底稿，再落水彩（`pencil.js` + `wash.js`）**：未染色的物体仅露出纸白、暗部石墨排线（Graphite Hatching）和屏幕空间铅笔外轮廓，绝无照片贴图。
2. **世界空间到达时间图（`createWash()`）**：`src/wash.js` 维护一张覆盖整片地面的时间纹理——脚步走过调用 `paint.touch(x, z, now)` 写入时间戳，到达终点樱花树时调用 `paint.flood()` 释放席卷全图的终局浪潮。
3. **万物定根（Root-Driven Climbing）**：每个顶点携带自己的取色根坐标与攀爬速度：
   - **地面**：自身即根，随脚步即时向四周晕开。
   - **大树**：根在树脚，颜料从树根沿树干与枝杈一路向上爬满树冠。
   - **花坛**：根定在花丛中心，一触即整片同时绽放。
   - **远山**：根取最近的步行地面边缘，随浪潮层层染透五重烟岚。

## 二、 核心视觉与性能设计

### 1. 颜料光学与冷紫二遍罩染（`src/wash.js`）
- 亮面尽可能保留纸白透底，颜料在纸纹低谷处汇聚沉淀，湿润前沿呈现最浓的水渍边（creeping rim），干燥后渐趋清透；暗部并非直接压黑，而是叠涂一层独立的**冷紫色水彩罩染（violet glaze）**。

### 2. 65 万点彩笔触（Brush Dabs，`src/glade/world.js`）
- 树叶、草丛与野花均由面向视角的笔触点彩构成：每一笔落下数片小叶、一簇草叶或一圈花瓣，浓淡各有随机起伏，且每个笔触都在颜料爬到自己那一刻才真正显现。整座森林合计约 **650,000 笔触**，1080p 桌面端帧耗时仅约 **4 ~ 6 ms**。

### 3. 深度感知湿画法（Wet-into-Wet，`src/page.js`）
- 远景与部分中景设为「湿纸区」，颜料仅在**深度相近的像素之间**相互晕染融合——因此树冠内部柔软如水彩洇开，而树冠面向天空的外轮廓以及未上色的铅笔线条依然保持干爽锐利。

### 4. 生命随色彩苏醒
- 只有被水彩染过的区域，草叶才会随风摇曳、溪水才会流淌、樱花瓣才会飘落、蝴蝶才会翩跹起舞。

## 三、 本地运行与调试参数

```bash
git clone https://github.com/N0tANTi/watercolour-walk.git
cd watercolour-walk
npm ci
npm run build
npm run serve
```

- 默认入口：http://127.0.0.1:5483/
- `?painted`：开场直接展示全图上色完成的终态水彩世界
- `?wet=0`：关闭全屏湿画法晕染，便于对照观察纯笔触与湿画法差异
