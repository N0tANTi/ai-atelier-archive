## 一、 协同创作核心分工原则

《天空之城》探索的是一套高度可复制的 **「人机协作三维短片制作工作流」**：

- **你来定（审美与导演决策）**：挑参考图、说清楚这一轮只改什么、看同机位对比预览、决定哪一版继续往下走。
- **交给模型（工程与执行）**：写 Blender Python 建模/着色/合成脚本、后台运行渲染、保存可编辑 `.blend`、输出多机位对照图、生成原创配乐并编码导出 MP4。
- **单轮单决策铁律**：每一轮发参考图时明确写清「只看这张里的什么」，保留固定检查机位（`构图检查`、`桥下检查`、`住宅检查`），用**同机位前后对比图**做验收。

## 三、 Blender Python 六大源码模块

整部短片无需外部 3D 模型库，只需 **Blender 5.2.1 LTS** 自带的 Python 与 NumPy 即可端到端重建：

- **`scene/build_cloud_village.py`**：总装入口，负责五段相机切换（1 / 121 / 241 / 346 / 436 帧）、水彩明暗节点、合成器纸面纤维与墨线边缘叠加，以及 EEVEE 1080p 视频导出。
- **`scene/cloud_village_buildings.py`**：程序化搭建主岛钟楼、半木结构主屋与阳台斜撑、七墩六孔石拱桥及副岛旋转风车。
- **`scene/cloud_village_land.py`**：雕刻带连续向下石脊的浮岛崖壁、分层树冠、苔草、崖边出水口瀑布及下层水潭。
- **`scene/cloud_village_air.py`**：布设漂移热气球、桥下花园与崖边木台等空中细节道具。
- **`scene/cloud_village_sky.py`**：分离式天空系统——远方云墙烘入环景天空，脚下三维近云层独立调高。
- **`scene/cloud_village_audio.py`**：使用 NumPy 合成 19 秒立体声原创配乐（轻竖琴、木笛、稀疏钟声与风声）并自动打包进 `.blend` 与成片。

### 从源码一键重建命令

```bash
blender --background --factory-startup --python-exit-code 1 --python scene/build_cloud_village.py -- --render
```

- 仅生成可编辑 `.blend` 工程（不渲染视频）：省略 `--render`
- 渲染快速预览小样：追加 `--percent 50 --samples 4`
- 另存版本目录：使用 `--output <目录>`；覆盖原目录需传 `--replace`

## 四、 十轮返修话术精华（踩坑即用）

- **岛间距过挤（Round 01）**：*“我选这台相机。右岛和主岛在画面里挤在一起，请只把右岛往右移到能读出两岛间的空隙，延长桥板接住右岸。把新旧两张图用原机位并排给我。”*
- **崖壁像叠饼（Round 02）**：*“请打散几圈整齐的水平边缘，让三道石脊跨过相邻高度连续向下。保留现有台面和桥头，用同一侧视再给我看。”*
- **桥孔被封死（Round 03）**：*“正面六个拱形已经对了，但从侧面看，第三孔里面被一整片面封住。请检查这一孔的几何，打通前后出口，保留上方石圈。”*
- **纸纹盖住细节（Round 08）**：*“选第②张的配色。第③张窗格和石缝被纸纹盖住了，请维持②的材质与曝光，把③的纸纹混合强度减半，并用原近景机位复拍窗格和石缝。”*
- **结尾音乐骤断（Round 10）**：*“最后一个镜头我喜欢，但音乐在画面结束时突然切断。请只让尾音在最后一秒内自然衰减，镜头时长与每个切点照旧。”*

## 五、 替换成你自己的素材怎么练？

1. **构图**：纸笔画两座不等大的岛、一条桥线、一高钟楼与一矮风车，发图时写明「只看构图关系」。
2. **建筑与配色**：拍一张喜欢的住宅侧面照圈出阳台；从风景照提取**明、暗、暖、冷**四块主色。
3. **跨对话续做**：新开对话时附上最近认可的 `.blend` 与脚本、上一轮预览图与当轮参考图，并明确说一句：*「以上一版为起点，我已选定……，这轮只改……」*。
