## 一、 四步「从 Blender 灰模到 WebGL2 月夜水园」实战提示词卡片

以下四条提示词整理自《月沼白堡 · Moonmere》的真实迭代流程，每张卡片均附带本项目渲染的对应阶段参考图，可直接预览与单张下载。

### 卡片 #1｜搭出池岸、拱廊和白堡的空间关系（Stage 01）
![01-framing.jpg](./refs/moonmere/ref-01-framing.jpg)
```text
[STAGE 01 · 空间与构图（上传 01-framing.jpg）]
1. 为一座月夜水园制作 Blender 灰模。先只用平面、盒体、圆柱和简单拱形。
2. 用接近水面的视点观察。前景左下方留给一朵白睡莲，两侧阔叶形成遮挡。
3. 池面中央留出一条可见的暗水带，让视线穿过中景的三联拱廊，落在远处白堡的主窗。
4. 白堡的圆塔略偏左，塔顶露出树冠。两岸高低错落，右岸为阶瀑与石龛留位置。
5. 转到 Three.js 重建时，先用约 40° 的垂直视角检查同一构图。
6. 白堡显得太小，先查体量和距离。三孔拱廊被遮住，先调树丛和岸线的位置。
7. 验收用一张全景和一张池边近景。两处都应读得出前、中、远景，再开始加细节。
```

### 卡片 #2｜给建筑、水面和睡莲做出不同的质感（Stage 02）
![02-stone.jpg](./refs/moonmere/ref-02-stone.jpg)
![03-lily-pond.jpg](./refs/moonmere/ref-03-lily-pond.jpg)
```text
[STAGE 02 · 石材、花瓣与浮叶（上传 02-stone.jpg + 03-lily-pond.jpg）]
1. 在已定好比例的 Three.js 水园里细化三处，保持主要建筑和观察位置稳定。
2. 白堡主窗加竖梃和环形花饰，圆塔加浅浮雕，拱廊用有厚度的楔形拱石和束柱。
3. 让石灰岩砌块的高度、冷暖和边缘磨损略有变化。檐下有纵向雨痕，近水处有湿缝。
4. 睡莲用四圈弯曲的双面薄瓣。迎光边缘透出柔白，互相盖住的地方偏灰紫。
5. 外瓣只有零星色点，淡黄色花蕊前低后密，从近处能看到浅色花心。
6. 浮叶按小群分布：大叶旁生出小叶，右岸的叶群互相叠压，池心留几块不规则暗水。
7. 从远处检查主窗和三个拱洞是否清楚。靠近水面检查瓣缘、叠影和叶群间的倒影。
```

### 卡片 #3｜先画出受光面，再统一月夜画风（Stage 03）
![04-shadow.jpg](./refs/moonmere/ref-04-shadow.jpg)
```text
[STAGE 03 · 月光、树影与色彩（上传 04-shadow.jpg）]
1. 把同一座水园处理成带插画感的月夜。先从左前上方打一盏偏冷的平行光，让树枝把影子投到墙和叶面上。用较弱的环境光保留暗部轮廓。
2. 在白堡正面和拱廊各给一处局部补光，使窗饰与石缝可读，同时保持近处林下的深影。
3. 按枝簇组织树冠的明暗：外层受光叶面趋向灰绿，内层连成深色轮廓。
4. 近景阔叶的叶脉要贴在叶面上，投影边缘收清楚，背光一侧仍有深浅变化。
5. 最后按颜色与亮度调整画面。轻轻归并绿色中间调，压低深影，保留细星、花瓣的淡灰紫叠影和浅石上的细纹。
6. 固定一个视角，开关调色，检查三处细节是否还在。
```

### 卡片 #4｜用 WebGL 2 实时渲染并检查结果（Stage 04）
![03-lily-pond.jpg](./refs/moonmere/ref-03-lily-pond.jpg)
```text
[STAGE 04 · 实时渲染、平面反射与离线打包]
1. 用 Three.js 的 WebGLRenderer 在浏览器实时绘制月夜水园，颜色以 sRGB 输出。
2. 让主月光生成阴影贴图。池面用平面反射，在正常画质下用 1024×1024 的纹理接收镜像相机的画面。用交错的小波纹扰动倒影，水隙里仍要能辨出岸边轮廓。
3. 主场景先画进离屏缓冲区，最后用全屏着色器处理暗部和绿叶中间调。
4. 提供可暂停的观察视图和调色开关。开关只切换最后的颜色处理，让使用者能在同一位置观察同样的建筑、灯光、树影和倒影。
5. 将依赖和场景代码打包到独立 HTML。离线打开，分别检查白堡全景和池边近景，再拖动画面转动视角，确认石雕有厚度、倒影随视角变化、花瓣边缘清楚。
```

## 二、 完整工程级 Master Prompt 模板（一键复现四阶段流水线）

```markdown
你是一位资深 Three.js 图形工程师与建筑场景美术总监。请按照「Blender 灰模构图 → Three.js 程序化建模 → 月夜插画光影 → WebGL2 实时反射与单文件打包」四步，独立构建一座可在浏览器离线运行的月夜水园《月沼白堡（Moonmere）》。

### 全局美术铁律
1. 构图必须保持清晰的三层纵深：前景左下透光白睡莲与阔叶画框、中景暗水带与三联石拱廊、远景树冠之上略偏左的圆塔与哥特主窗白堡。
2. 所有几何结构（主窗竖梃、环形花饰、楔形拱石、四圈弯曲花瓣）必须具备真实厚度以承接月光侧影，严禁退化为平面贴片。
3. 调色后处理必须严格解耦为离屏全屏 Pass，并向用户暴露「调色开关」，确保不改变任何几何与灯光即可对比原始渲染与插画月夜成片。

### 分阶段实现要求
1. 空间与构图校准（Stage 1）：先用基础几何体确立 40° 垂直视角的全景与池边近景双机位，确认白堡体量、三联拱廊通透度以及右岸阶瀑与石龛的空间留白。
2. 石材、花瓣与浮叶细节（Stage 2）：在 `architecture.js` / `castle-ornament.js` 生成石灰岩变色砌块、纵向雨痕与近水湿缝；在 `garden.js` 实现四圈双面薄瓣睡莲、花瓣叠压灰紫阴影与按小群分布的池面浮叶。
3. 月光、树影与插画统一（Stage 3）：从左前上方架设冷色平行月光并开启阴影贴图，为白堡正面与拱廊补充克制的局部面光，按枝簇组织树冠外亮内深轮廓。
4. 平面镜面反射与离线打包（Stage 4）：在 `water.js` 实现 `1024×1024` 镜像相机平面反射与交错波纹扰动；在 `finish.js` 实现归并绿色中间调与压低深影的全屏着色器；通过 `build.mjs`（esbuild）打包为单文件自包含 HTML（支持基础版、`--refined`、`--engraved` 三档版本）。

请每完成一个阶段先输出全景与池边近景双视角验收结果，确认无误后再推进下一阶段。
```
