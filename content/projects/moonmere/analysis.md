## 一、 为什么先用 Blender 定构图，再回 Three.js 重建？

纯代码写 3D 场景最容易陷入的陷阱，是一开始就埋头雕花，结果拉远一看发现**城堡太小、拱廊被树叶挡死、睡莲和远景比例失调**。

`moonmere-three` 采取了一条非常克制的双轨工作流：

1. **Blender 灰模先行（`scene/build_moonmere.py`）**：只用平面、盒体、圆柱和简单拱形搭建白堡圆塔、三联拱廊、两岸陡崖与右岸阶瀑石龛，用接近水面的低机位反复推敲「前景睡莲 → 中景暗水与拱廊 → 远景白堡主窗」的三层穿插关系。
2. **锁定 40° 垂直视角后转入 Three.js（`scene/moonmere_three/`）**：将确认无误的体量与距离直接映射为参数化 JS 模块，确保从全景拉到池边近景时，所有建筑、水线与植物比例严丝合缝。

## 二、 核心模块拆分与几何哲学

| 模块文件 | 核心职责 | 关键工艺细节 |
| --- | --- | --- |
| `architecture.js` & `castle-ornament.js` | 白堡主体、圆塔浅浮雕与三联拱廊 | 窗梃、环形花饰、楔形拱石和束柱全部以真三维几何生成，侧面能承接冷月光；石灰岩砌块自带高度/冷暖微差、檐下纵向雨痕与近水湿缝 |
| `garden.js` | 睡莲、浮叶群、阔叶画框、崖壁藤蔓与柏树林冠 | 睡莲由四圈弯曲双面薄瓣构成，迎光边缘透出柔白、叠压处偏向灰紫；浮叶按大小成群分布，池心特意留出不规则暗水带承接倒影 |
| `water.js` | 池面平面反射与波纹扰动 | 使用镜像相机将天空、白堡与两岸植被实时渲染至 `1024×1024` 反射纹理，再通过交错小波纹 UV 扰动取样，既保留液面微澜又不破坏水隙中的建筑倒影轮廓 |
| `sky.js` | 满月、星野与冷色云峰 | 在深邃夜空中布置层次分明的星点与高反差月光云墙，将白堡与深绿林冠稳稳托出剪影 |
| `finish.js` | 离屏全屏插画调色 Pass | 将主场景先渲染入离屏缓冲区，再由全屏着色器轻量归并绿色中间调、压低林下深影，同时保护白花瓣、细星芒与浅石细纹不发灰 |
| `scene.js` & `viewer.html` | 相机轨迹、灯光系统与交互检视面板 | 支持拖动进度条浏览全景至池边近景、随时暂停并自由旋转视角，并提供独立的「调色」实时开关做同机位 A/B 对比 |

## 三、 月夜插画感的关键：先控光，再克制地做全屏调色

如果把所有月夜氛围都压给后期滤镜，画面通常会变得脏灰或死黑。Moonmere 把「空间打光」和「色彩归并」明确拆成了两步：

- **第一步：物理层级打光**
  - 左前上方架设一盏偏冷的主平行月光并开启阴影贴图，让树枝真实投影到崖壁与阔叶表面；
  - 在**白堡正面**与**三联拱廊**分别架设极克制的局部补光，使主窗花饰和拱石接缝在远处依然清晰可读，而近处树林下方保持沉静深影；
  - 树冠按枝簇组织明暗，外层受光叶片趋向灰绿，内层自然连成深色块面。
- **第二步：可开关的离屏着色器（`finish.js`）**
  - 只处理最后的色彩与影调映射，不改动任何几何、灯光或倒影逻辑；
  - 点击画布中的「调色」按钮即可在同一静止帧上秒切前后对照，是复盘风格化渲染管线最直观的验收方式。

## 四、 三档构建模式与零依赖单文件分发

`scene/moonmere_three/build.mjs` 使用 `esbuild` 将 Three.js 依赖与全部场景模块内联进 `viewer.html`，并按迭代阶段支持三种独立编译参数：

```bash
# 基础结构版 → output/moonmere_three/moonmere.html
node scene/moonmere_three/build.mjs

# 中间材质细化版 → output/moonmere_three_refined/moonmere.html
node scene/moonmere_three/build.mjs --refined

# 最终雕刻与完整调色版 → output/moonmere_three_engraved/moonmere.html
node scene/moonmere_three/build.mjs --engraved
```

这种通过编译期宏（`__MOONMERE_REFINED__`、`__MOONMERE_ENGRAVED__`）控制细节层级的方式，不仅能一键生成可完全离线双击打开的单 HTML 作品，还能在同一个代码库里完整保留「灰模 → 材质 → 精雕调色」三个里程碑版本。
