## 一、 核心视觉叙事：从宣纸线稿到水彩设色

《雨过山寺》以 **Three.js + 自定义 GLSL 着色器** 完整模拟了水彩作画的物理与时间过程：

1. **初始线稿态**：画面呈现微暖宣纸底色（`#F6F1E6`），山寺、廊桥与人物仅由石墨暗部排线（Graphite Hatching）和铅笔外轮廓构成。
2. **拨动竹槽引水**：点击竹槽或按 `E` 键后，行者通过 2-Bone IK 伸手拨动竹槽，水流顺廊桥奔涌而出，同时唤醒配乐《过桥听雨》与实时雨声。
3. **沿根部实时晕染**：水彩不是整屏淡入，而是通过地面时间图（`uMap`）追踪水流抵达时刻——色彩从建筑与树木的「根部（`root`）」向上攀爬浸润，湿润前沿颜色最浓，干后在纸纹低谷处沉淀出柔和不均的水渍与冷紫色二遍罩染。

## 二、 核心模块架构拆解

### 1. 宣纸铅笔线稿与水彩扩散着色器（`wash.js` / `pencil.js` / `page.js`）
- **世界空间时间图（`wcAge`）**：`createWash({ x0: -32, z0: -35, size: 68, cells: 384 })` 维护一张覆盖山寺地面的时间纹理，片元着色器根据 `uNow - T - climb - rag` 计算颜料抵达后的湿润时长，并用三层 3D 噪声制造参差不齐的水痕前沿。
- **水彩光学建模（`wcPaint`）**：先以 `pcTooth` 和 `pcStrokes` 绘制宣纸颗粒与石墨排线；染色阶段计算湿润度 `wet` 与前沿浓边 `rim`，呈现「亮部透纸白、湿边色最深、干后渐清透」的真实画纸质感。
- **全屏画纸后处理（`page.js`）**：叠加整幅画面的纸张肌理、边缘铅笔勾线与全局湿润度（`page.wet.value = 0.76`）。

### 2. 程序化山寺建筑与天气水体（`temple.js` / `shape.js` / `temple-weather.js`）
- 山寺殿宇、飞檐、廊桥、竹槽及悬崖苍松全部通过参数化几何工具（`shape.js`）在代码中生成，避免庞大外部模型包。
- `temple-weather.js` 负责远山层叠烟岚、雨丝飘落与水体动态流动，与引水事件同步推进。

### 3. 武侠行者与骨骼 IK 交互（`wayfarer.js` / `figure/man.js`）
- 在基础骨骼网格之上，代码动态生成并缝合了**竹编斗笠**（多层环线 + 帽绳）与**背负式长剑**（绑定至 `spine_03` 骨骼，含木鞘、黄铜箍饰、缠柄与剑穗）。
- 内置轻量级 **双骨骼逆向运动学（2-Bone IK `reach()`）**，让行者在引水触发瞬间自然抬起右肩与前臂伸向竹槽目标点。

### 4. 配乐融合与实时声景（`temple-sound.js`）
- 将《过桥听雨》（`public/audio/过桥听雨.m4a`）主旋律与 Web Audio API 实时合成的雨声、檐下滴水声及铜铃声混音，营造东方雨夜氛围。

## 三、 本地运行与单文件离线打包

项目基于 `Node.js 24 + Vite 8 + Three.js 0.186`，执行 `npm run build` 除生成标准静态目录 `dist/` 外，还会在上级目录自动内联模型与音频，打包出可直接双击打开的离线单文件 `雨过山寺.html`：

```bash
git clone https://github.com/N0tANTi/rain-temple-wuxia.git
cd rain-temple-wuxia
npm ci
npm run build
npm run serve
```

### 交互操作速查

| 按键 / 操作 | 效果 |
| :--- | :--- |
| 点击竹槽 / `E` | 拨动竹槽引水上色，并开启配乐与雨声 |
| 鼠标拖动 / 滚轮 | 环视山寺与缩放景别 |
| `R` | 重置水流与重新引水 |
| 点击「观看短片」 | 场景内自动引水并跟随电影镜头游览 |
