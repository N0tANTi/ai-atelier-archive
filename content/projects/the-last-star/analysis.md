## 一、 一鱼两吃：短片电影 × 交互绘本双形态架构

《最后一颗星》把同一个故事同时落地成了两种完全不同的交付介质，且均做到「零外部素材依赖、全部由代码生成」：

1. **Blender 5.2 纯 Python 动画管线（`src/*.py` + `render.ps1`）**：一键生成 10 个完整分镜、共 `1,416` 帧（`00:00–00:59 @ 24fps`）的 `1280×720` 中文高清短片 `TheLastStar.mp4`，并通过 Blender VSE 自动混音封装；
2. **零依赖 HTML5 Canvas 绘本小游戏（`docs/index.html`）**：单个 49 KB 的自包含 HTML 文件即可在 GitHub Pages 或离线浏览器直接运行，内置基于 Web Audio API 的实时竖琴与钢片琴交互音轨。

## 二、 Blender 5.2 七大 Python 模块分工

| 模块文件 | 核心职责 | 工艺亮点 |
| --- | --- | --- |
| `src/npr.py` | 法式水粉 2.5D NPR 着色器系统 | 结合 `ShaderToRGB` 阶梯明暗、柔和纸面颗粒、反转法线/线条墨线描边，以及合成器四角星芒柔光 |
| `src/robot.py` | 单眼圆头小机器人与提灯 | 全程序化组装圆顶头壳、黄铜眼眶、青色腰环、天线光球与提灯，驱动行走、抬头仰望与伸手接星动作 |
| `src/observatory.py` | 天文台外景、内景与双球蔡司星象仪 | 生成石砖筒身、可滑动开启的金属穹顶天窗、环形铁艺石廊、室外电线杆与碟形天线，以及室内双球多镜头星象仪 |
| `src/fx.py` | 银河星尘涡流、星座星鲸与中文手写片尾 | 以 30 个控制点构建平滑的半透明星座座头鲸，叠加青绿/淡紫三层流动极光带、涌出穹顶的星尘流与中文手写片尾 |
| `src/shots.py` | 全片 10 个分镜调度（`1,416` 帧） | 编排暮色外景、机器人特写、室内星象仪启动、银河喷涌广角、星鲸游弋、走廊接星与片尾落幕 |
| `src/sound.py` | 纯 NumPy 59 秒立体声原声配乐 | 无需外部采样库，直接用 NumPy 合成与镜头节拍严密对齐的竖琴、钢片琴氛围音乐与环境音效 |
| `src/pipeline.py` & `render.ps1` | 预览、正式渲染与 VSE 自动封包 | 支持 `-Mode preview` 快速渲染 10 个关键帧验收，或 `-Mode render` 输出完整带配乐 MP4 |

## 三、 在线四幕互动绘本玩法（`docs/index.html`）

网页版将短片的高光镜头转化为四幕可亲手触发的互动体验，每一步操作都会实时触发对应的 Web Audio 和弦与粒子反馈：

1. **第一幕 · 暮色天文台**：按 `A / D`、`← / →` 或直接点击画面移动提灯小机器人，点亮圆形暖窗并推门走入天文台；
2. **第二幕 · 唤醒星象仪**：点击或按空格逐一点亮双球星象仪上的 **7 枚黄铜星辰镜头**，伴随渐高的竖琴音阶缓缓滑开穹顶天窗；
3. **第三幕 · 连线星鲸与极光**：依次点击或划过夜空中闪烁的星座光点，亲手连出巨型星座座头鲸并唤醒三层极光；
4. **第四幕 · 接住最后一颗星 & 自由观星**：在天文台环形石廊上接住飘落的金色星光，随后解锁自由观星模式，在夜空中随心挥洒星尘。

## 四、 本地复现与一键渲染命令

需安装 **Blender 5.2**（自带 Python 与 FFmpeg 合成环境，无需额外 `pip` 安装）：

```powershell
# 1. 快速渲染全部 10 个分镜关键帧预览（便于调试构图与 NPR 质感）
.\render.ps1 -Mode preview -Width 960 -Height 540 -Samples 16

# 2. 渲染完整 59 秒 1280×720 24fps 高清动画短片（含 NumPy 合成的立体声配乐）
.\render.ps1 -Mode render -Width 1280 -Height 720 -Samples 12
```
