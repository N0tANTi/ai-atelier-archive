## 一、 视频内 6 张「屏幕悬浮精炼卡」（直接用于字幕/卡片动画）

### 卡片 #1｜地形与笔触（Stage 1）
```text
[PROMPT 01 · 地形骨架与反噪点铺底]
1. 禁止写实照片贴图与高频噪点，保持大色块干净可读
2. 用平滑 FBM + 高斯坡度生成山谷盆地与蜿蜒土路，视野中央保持通透
3. 用 Canvas 程序化生成 512px 无缝椭圆笔触图（大/中/小三层），按多尺度叠加到地面
```

### 卡片 #2｜风吹草海（Stage 2）
```text
[PROMPT 02 · 4 圈 LOD 实例化草海]
1. 用 4 圈跟随相机的 InstancedBufferGeometry（近密 8 段 → 远疏宽簇）
2. 位置与朝向由世界网格哈希决定，边界按随机距离淡出，消除闪烁与跳变
3. 草叶着色读取地面笔触图与坡度，配合滚动风场噪声形成大片色块草浪
```

### 卡片 #3｜天空、体积云与远山（Stage 3）
```text
[PROMPT 03 · 零帧率开销的烘焙天幕]
1. 积雨云：堆叠球体 + 3D 膨胀噪声 Raymarching，离线烘焙到 Cubemap，仅分 4 阶硬朗色块
2. 远山：预烘焙高度图 + 锐利分面（ridged noise）Raymarching 成 360° 全景条带
3. 全景条带存储「亮色 / 暗色 / 受光 / 雾度」，切换日落时实时重打光无需重绘
```

### 卡片 #4｜球团树冠与程序村庄（Stage 4）
```text
[PROMPT 04 · 动画式造物法]
1. 树冠由多个球形叶团组成，叶片法线强制指向所在球团球心外侧，呈现动画云团明暗
2. 将树荫烘焙到世界阴影图供草地读取，并加入随风晃动的树影光斑
3. 远景村庄在片元着色器中按局部坐标程序绘制瓦片、屋檐阴影与暗窗，用 fwidth 抗闪烁
```

### 卡片 #5｜赛璐璐主角与 Alpha 暗码（Stage 5）
```text
[PROMPT 05 · 人物赛璐璐 + Alpha 通道编码]
1. 三阶平涂：亮面色 + 独立手调偏冷暗面色（禁止压黑）+ 布料深褶皱色
2. 披风采用实时布料模拟，计算顶点褶皱度，并在暗部叠抗锯齿细钢笔排线
3. 将部位 ID 写入渲染目标 Alpha 通道：角色 0.03~0.21 | 远景 0.25~0.59 | 草地 1.0
```

### 卡片 #6｜终极后处理管线（Stage 6）
```text
[PROMPT 06 · 分层 Kuwahara + 深度感知暖墨线 + 画家调色]
1. 分距离平滑 Kuwahara 笔触滤镜：中景 r=2，近远景 r=1，跳过 alpha < 0.6 的角色与远景
2. 检测 alpha < 0.23 的相邻 ID 边界画暖棕色墨线；比对深度缓冲，前景草叶遮挡时不描边
3. 替换 ACES 为画家保色曲线，叠加统一「暖纸白 + 蓝黑墨」底色与 4 套时间色板插值
```

## 二、 完整工程级 Prompt 模板

```markdown
请使用 Three.js (WebGL2 + GLSL3) 构建一个可实时交互的「手绘动画电影风格」3D 探索场景。

### 全局美术铁律
- 禁止写实 PBR 照片贴图与高频噪点，全场景共享同一套手绘线性光调色板。
- 背景环境采用“水粉笔触感”，主角采用“三阶赛璐璐平涂 + 细墨描边”，通过材质反差突出主体。
- 所有程序化高频细节（瓦片、布料钢笔排线等）必须基于 `fwidth()` 做像素级抗闪烁衰减。

### 模块化分阶段实现要求
1. **地形与笔触（Stage 1）**：
   - 使用多尺度 FBM 与高斯山丘函数构建开阔山谷、蜿蜒小路与远方湖泊，确保视角中轴通透。
   - 用 2D Canvas 程序化绘制 512×512 无缝椭圆笔触贴图，作为地形与草地共享的色调起伏源。
2. **多圈 LOD 风吹草海（Stage 2）**：
   - 建立 4 圈跟随相机的实例化草叶环（近景高密 8 段、中景 4 段、远景 3 段宽簇），细胞坐标由世界网格确定性哈希生成。
   - 草叶顶点受方向风场与阵风波浪驱动，色块与地面笔触联动。
3. **离线烘焙天空、积雨云与分面远山（Stage 3）**：
   - 三段渐变天空穹顶 + 太阳散射光晕。
   - 积雨云由堆叠球体 + 3D Worley 膨胀噪声构成，Raymarching 烘焙至 Cubemap，输出 4 个清晰色阶。
   - 远山预烘焙 2D 高度图，Raymarching 烘焙至 360° 全景多通道贴图（亮色、暗色、受光、空气透视），随时间动态重新着色。
4. **球团树木与程序村庄（Stage 4）**：
   - 树干由曲线管道生成，树冠为多个叶团球；叶卡法线取球团中心向外方向，避免碎叶发黑。
   - 远景村庄建筑基于局部坐标在 Fragment Shader 中程序绘制屋瓦、檐下阴影与门窗。
5. **赛璐璐主角、布料披风与 Alpha-ID 编码（Stage 5）**：
   - 角色着色采用三阶平涂（亮面、手调冷暗面、褶皱深色），披风实时布料模拟并输出褶皱属性与钢笔排线。
   - 在 Fragment Shader 中用 `outColor.a` 编码材质分组：角色各部件写 `0.03~0.21` 唯一 ID；已手绘远景写 `0.25~0.59`；接受笔触滤镜的草地写 `1.0`。
6. **统一后处理与时间系统（Stage 6）**：
   - 单 HDR RenderTarget + DepthTexture 渲染管线。
   - 分距离加权 Kuwahara 滤波（跳过 `alpha < 0.6` 像素，中景半径 2，近远景半径 1）。
   - 深度感知暖墨描边：仅对 `alpha < 0.23` 的 ID 跳变处画线，且当非角色像素深度更近时（草叶遮挡）跳过描边，线色为底层色压暗偏暖。
   - 采用保色高光滚落曲线，叠加统一「暖纸白 + 蓝黑墨」色偏，并内置正午/午后/黄金时刻/日落 4 套线性光色板插值切换。

请按 Stage 1 → Stage 6 分阶段输出可运行代码，每完成一个阶段提供验证方式后再进入下一阶段。
```
